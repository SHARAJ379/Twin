# Code of Conduct

Be respectful. Disagree about code, not about people. No harassment, personal attacks, or
discriminatory language in issues, PRs, discussions, or any other project space.

Maintainers may edit, lock, or remove comments/issues/PRs that violate this, and may block
repeat offenders.

Report conduct issues by opening a GitHub issue tagged for a maintainer's attention, or via the
contact method on the maintainer's GitHub profile if the report concerns a maintainer.
